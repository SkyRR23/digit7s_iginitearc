# Action and decision update — October 29, 2026

This updates the game from the October 28 shared-PC recap. The original recap and ZIP backup are reference material; the code in this repository is the development source.

- At seven Doubt, the **accuser** chooses which hidden Life card to flip. The server opens a ten-second decision, preserving the current turn's remaining time. The choice is validated on the server; timeout flips the first remaining hidden position. Multiple Heart accusations queue in order. An accusation does not automatically mean death: an Ashbound Life or the last remaining hidden Life still causes elimination under the existing rules.
- Existing synchronized close-ups pause the decision clock too. Finishing a close-up early shows a waiting message until the other readers finish. While a Life choice or Bell vote is active, normal actions wait. The countdown appears above the Life choices.
- Evidence is **+1** Doubt, Testimony is **+3**, and Witness raises the row to **7**. Piety blocks all three. Heart sharing happens once per played pressure card.
- The old effect-removal card is **Dispel** (internal kind `DISPEL`). The Black Cat attachment is now **Curse** (`CURSE`, with `BLACK_CAT` retained as its status identifier). Dispel names the actual removed effect in the confirmation, public close-up, and table feedback. Removing Curse returns that same card to the draw pile. The opening Ashbound choice attaches the single existing deck Curse; Dispel returns it to the draw pile. Scapegoat preserves the attached card when transferring effects; death discards attached Curse cards.
- **Conspiracy resolves immediately when drawn**, then draws continue toward the normal two-card draw. Opening hands exclude Conspiracy, so it can no longer be held indefinitely and bypass the first Night. It reveals a random hidden Life on living Curse holders, then shifts hidden Lives among survivors. It safely skips the exchange if fewer than two living players remain or victory has already been reached.
- Revealing Lanternkeeper leaves the holder alive unless that was their last hidden Life. Its night protection ends immediately. This behavior already existed and now has explicit regression coverage and reveal copy.
- **Eavesdrop is a card, not an additional role.** It privately shows a twelve-second snapshot of another player's playable hand. The target keeps those cards. Other clients never receive the snapshot. It respects presentation pauses and is covered on blur/dismissal. Herbalist remedy can block it.
- **Council Bell** is the sole card that opens voting. Exactly one is in the match deck, and playing it spends it permanently. Its close-up says “Hear ye, hear ye!” and rings a short sound when sound is enabled. A thirty-second vote pauses the normal turn. A strict majority eliminates its target; otherwise all ballots or the deadline end the vote without elimination. Scapegoat's vote-only individual win remains supported. Voting outside the Bell session is rejected on the server.
